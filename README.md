# MarketPulse Real-Time Stock Pipeline

[![CI](https://github.com/ngozi-nnajim/marketpulse-pipeline/actions/workflows/ci.yml/badge.svg)](https://github.com/ngozi-nnajim/marketpulse-pipeline/actions/workflows/ci.yml)

A real-time data pipeline that ingests intraday stock prices from Alpha Vantage,
streams them through Apache Kafka, processes them with Apache Spark Structured
Streaming, stores results in PostgreSQL, and visualises them in Metabase.
Everything runs locally with Docker Compose.
